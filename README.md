# Snack Match

A generic twenty-food photo carousel. Swipe or tap yes/no, undo, then build a small example menu and shopping list. Choices remain in browser local storage; export or share them manually. No account, analytics, payment or uploaded selection backend.

The food/portion examples are illustrative, not a prescribed diet or allergen guarantee. Check actual product labels. Food photographs retain the licences in PHOTO_CREDITS.md.
