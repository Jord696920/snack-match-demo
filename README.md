# Snack Match

100 food-photo ideas in one continuous deck, with optional Save & pause and Continue choosing. No forced rounds. The original twenty IDs, browser storage key and backup format remain compatible.

Food, prep-time and portion examples are illustrative, not nutritionally complete prescriptions or tested recipes. Active time is distinct from heating/cooking/chilling time; many ideas assume explicitly bought or previously cooked ingredients.

Selections remain in browser local storage. Share/export occurs only on an explicit user tap; there is no account, analytics, payment or selection-upload backend. General food/supplement notes link Australian guidance, not personal medical records or a prescribed regimen.

Photo licences are in PHOTO_CREDITS.md and the app.
